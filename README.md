# Array Exercises in Java

This repository contains a collection of **Java array exercises** developed during the **1st semester at Etec**, as requested by the programming professor.  
It serves both as practice material and as part of a **portfolio** to showcase fundamental Java programming skills.

---

##  Features
- Exercises focused on **array manipulation** in Java.  
- Covers basic operations such as:
  - Declaring and initializing arrays.  
  - Iterating through arrays with loops.  
  - Performing calculations (sum, average, min, max).  
  - Searching and sorting elements.  
- Simple, well-structured code for learning purposes.

##  How to Run
### Prerequisites
- **Java Development Kit (JDK) 8+** installed.  

### Steps
1. Clone the repository:
   ```bash
   git clone https://github.com/GabrielSantana1996sp/Array_Java.git
   cd Array_Java
   ```
2. Navigate to the exercise file you want to run.  
3. Compile the file:
   ```bash
   javac ExerciseName.java
   ```
4. Run the program:
   ```bash
   java ExerciseName
   ```
